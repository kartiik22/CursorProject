# TipSplit

A small tip & bill splitter you can open in any browser — no build step, no dependencies.

## Run it

1. Open `index.html` in your browser (double-click, or drag it into a tab).
2. Or from this folder:

```bash
open index.html
```

Enter a bill, pick a tip (or type a custom %), split between people — tip, total, and per-person amounts update live.

## What Cursor helped me create

Cursor scaffolded TipSplit from a blank folder into a single working HTML page with live tip math, preset and custom tip options, and a people splitter. It also helped debug the totals so they recalculate whenever the bill, tip percent, or party size changes.
